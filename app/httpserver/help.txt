httpserver - Simple HTTP server for serving directories

Usage:
  httpserver [OPTIONS]

Environment Variables:
  PORT        Port to listen on (default: 8000)
  HOST        Host to bind to (default: 0.0.0.0)
  SERVE_DIR   Directory to serve (default: current directory)

Examples:
  httpserver                    # Serve current directory on port 8000
  PORT=3000 httpserver          # Serve on port 3000
  SERVE_DIR=/data httpserver    # Serve /data directory

Features:
  - Serves static files over HTTP
  - Automatic directory listing
  - Content-type detection
  - Runs in isolated Docker container
  - Preserves file permissions

Notes:
  - Press Ctrl+C to stop the server
  - Access the server at http://localhost:PORT
  - The server runs with your user permissions
