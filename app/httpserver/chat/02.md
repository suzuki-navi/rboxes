I've added the cache-disabling headers to the HTTP server application. The changes were made to the `CustomHTTPRequestHandler.end_headers()` method in `app/httpserver/src.md`:

```python
def end_headers(self):
    """Add custom headers"""
    self.send_header('Server', 'rboxes-httpserver')
    self.send_header('Cache-Control', 'max-age=0')
    self.send_header('Expires', '0')
    super().end_headers()
```

The application has been rebuilt successfully. Now all HTTP responses from the server will include:
- `Cache-Control: max-age=0` - Tells browsers and proxies not to cache the content
- `Expires: 0` - Sets expiration to the epoch time, ensuring content is considered immediately stale

These headers will prevent browsers from caching any files served by the HTTP server.
