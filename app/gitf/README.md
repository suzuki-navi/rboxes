# gitf

Git diff helper for comparing branches

## 概要

ブランチ間の差分を表示する簡素化されたヘルパーツールです。指定されたブランチと現在の状態との差分を色付きで表示し、`less`ページャーで閲覧します。

## 使用方法

```bash
gitf <branch> [git-diff-options...]
```

### 引数

- `<branch>` - 比較対象のブランチ名またはブランチ範囲（例: `main`, `main..HEAD`）
- `[git-diff-options...]` - `git diff`に渡す追加オプション（オプション）

## 動作

- ブランチ範囲が指定されていない場合（`..`を含まない場合）、自動的に`<branch>~..<branch>`に展開されます
- ターミナル出力の場合、以下の情報を色付きで表示します：
  - ブランチの最新コミット情報（単一ブランチ指定時）
  - ファイルの変更ステータス（`--name-status`）
  - 変更の統計情報（`--stat`）
  - 詳細な差分（`diff`）
- 結果は`less -X -R -S`でページング表示されます
- パイプ出力の場合、色なしで同じ情報を出力します
