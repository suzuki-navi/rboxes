# updatebacklinks

Markdownファイル間のバックリンクを自動更新するPerlスクリプトです。

## 概要

指定されたディレクトリ内の`.md`ファイルをスキャンし、ファイル間のリンク関係を解析して、自動的にバックリンクを管理します。ナレッジベースやwikiのような相互参照システムに適したツールです。

## 目的と用途

- ObsidianのVaultで利用することを想定しています
- Backlinkを明示的にMarkdownに記載することで、Claude CodeなどのAIツールがMarkdownファイルから情報をたどりやすくするためです

## 使用方法

```bash
updatebacklinks -d <target_directory>
```

### オプション

- `-d <directory>`: 対象となるMarkdownファイルが格納されたディレクトリを指定

### 使用例

```bash
# カレントディレクトリのMarkdownファイルを処理
updatebacklinks -d .

# 特定のディレクトリを処理
updatebacklinks -d /path/to/notes
```

## 機能

### リンク形式の対応

以下のMarkdownリンク形式に対応しています：

- 標準形式: `[リンクテキスト](ファイル名.md)`
- Wiki形式: `[[ファイル名]]`

### 処理の流れ

1. **ファイルスキャン**: 指定ディレクトリ内の`.md`ファイルを最新更新日時順にスキャン
2. **リンク抽出**: 各ファイルの本文からMarkdownリンクを抽出
3. **バックリンク追加**: リンク先ファイルに自動的にバックリンクを追加
4. **バックリンク検証**: 既存のバックリンクセクションを検証・更新
5. **処理制限**: 一度に最大5ファイルまで処理

### バックリンク管理

- バックリンクは`%backlinks`セクションに自動管理されます
- 双方向のリンク関係を維持します
- 存在しないファイルへのリンクは自動的に削除されます

### 技術的特徴

- **コードブロック対応**: コードブロック内のリンクは処理対象から除外
- **ファイル存在確認**: リンク先ファイルの存在を確認
- **重複防止**: 既存のバックリンクとの重複を防止
- **タイムスタンプ管理**: 最新更新順での処理優先度

## バックリンクセクションの例

```markdown
%backlinks
- [[関連ファイル1]]
- [リンクテキスト](関連ファイル2.md)
```

## 注意事項

- 処理対象は`.md`拡張子のファイルのみです
- 一度の実行で最大5ファイルまでしか更新されません
- バックリンクセクション(`%backlinks`)は自動管理されるため、手動での編集は推奨されません

## 要件

- Perl 5.x以上
- 対象ディレクトリへの読み書き権限
