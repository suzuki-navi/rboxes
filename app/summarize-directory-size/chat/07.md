## 推奨設計

**デフォルト動作**: `.gitignore` に従ってファイルを除外（現在の `--gitignore` の動作）

**新オプション**: `--no-gitignore` または `--include-ignored` で `.gitignore` を無視して全ファイルを表示

### 理由

1. **一般的なユースケース**: 開発者がディレクトリサイズを確認する際、通常は `.gitignore` されているファイル（`node_modules/`, `target/`, `.git/` など）を含めたくないことが多い
2. **直感的**: Git 管理されたプロジェクトでは、Git が追跡しているファイルのサイズを見たいという需要が自然
3. **既存ツールとの一貫性**: `du` や `ncdu` などの既存ツールも、多くの場合除外パターンを指定する方が一般的

### 実装案

```rust
--no-gitignore    Disable .gitignore filtering (show all files including ignored ones)
```

または

```rust
--include-ignored    Include files matched by .gitignore patterns
```
