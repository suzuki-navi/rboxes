# AI

`lib/lib.sh` の `build_app` 関数を修正し、ハッシュベースのインクリメンタルビルドを実装しました。

## 実装内容

1. **ハッシュ計算**: `git ls-files` でアプリディレクトリ内の全Git管理ファイルを列挙し、各ファイルの内容をsha256sumでハッシュ化、さらにそれらを結合してアプリ全体のハッシュ値を生成します

2. **ハッシュ保存**: 前回ビルド時のハッシュ値を `lib/build-hash/<app_name>.txt` に保存します

3. **ビルドスキップ判定**:
   - 前回のハッシュと現在のハッシュが一致
   - かつ、ビルド済みの実行ファイルが存在する場合
   - ビルドをスキップします

4. **`.gitignore` 更新**: `/lib/build-hash` をgitignoreに追加し、ハッシュファイルをバージョン管理から除外しました

## 動作

- ファイルに変更がない場合: "Skipping build for <app_name> (no changes detected)" と表示してビルドをスキップ
- ファイルに変更がある場合: 通常通りビルドを実行し、成功後に新しいハッシュ値を保存

この実装により、変更のないアプリのビルドをスキップして、ビルド全体の時間を短縮できます。
